# Hi, I'm Marcello 👋

**Software Engineer | Full Stack & AI** · Lavras, MG, Brazil

I build software that automates real business processes, from AI agents that talk to customers to integrations between enterprise systems running at scale.

I hold a B.S. in Control and Automation Engineering (UFLA) and work as a Software Engineer at **Levty**, delivering web, mobile and AI solutions for enterprise clients in the financial, industrial and public sectors. My automation background shapes how I work: understand the process first, then make different systems work together end to end.

---

### 🚀 What I've been building

- **AI agent for customer collections**: answers questions, negotiates, makes retention offers and sends payment slips over WhatsApp, using RAG with embeddings filtered by customer profile. Delivered in 2 months, in an operation with **1M+ conversations**.
- **WhatsApp chatbot platform**: stabilized a failing chatbot (**90%+ fewer support tickets**) and then designed and shipped 5 new flows end to end.
- **Enterprise integrations**: **50+ client APIs** integrated and **20+ business processes** (credit analysis, quota transfers) on a platform handling ~200k tickets.
- **Document automation**: a service that reads and cross-references PDFs to generate customer receipts, replacing a manual process (~200 receipts/day).

> Most of this work is under NDA, so the code isn't public, but I'm happy to talk about the architecture and decisions behind it.
